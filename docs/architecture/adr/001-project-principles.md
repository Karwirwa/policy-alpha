# ADR 001: Project Principles

## Status
Accepted

## Context
Policy Alpha is an intelligence platform, not a general-purpose chatbot. The project must remain grounded in evidence, structured data, and a durable engineering foundation.

## Decision
The project will follow a set of enduring principles:

- AI is a reasoning engine, not the system of record.
- Retrieval before reasoning.
- Strong foundations over premature complexity.
- Build incrementally.
- Evidence before conclusions.

## Why this matters
These principles keep the platform focused on trustworthy analysis and maintainable architecture rather than model hype or premature feature expansion.
