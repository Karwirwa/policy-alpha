# 0001: Recommended Tech Stack

## Status
Accepted

## Context
PolicyAlpha needs a scalable foundation for a modern web application with a backend API and a user-facing frontend.

## Decision
Use a full-stack setup with:
- Frontend: React with TypeScript
- Backend: Node.js with Express or Fastify
- Database: PostgreSQL
- Deployment: Docker-based local development and cloud hosting later

## Consequences
- Faster development with a familiar modern stack
- Easier maintainability and team onboarding
- Clear path to future scaling and integrations
